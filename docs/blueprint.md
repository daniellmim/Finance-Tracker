# **App Name**: SpendWise

## Core Features:

- Expense Input: Allow users to manually input their expenses, specifying the amount, category, and date.
- Category Creation: Enable users to create custom expense categories.
- AI-Powered Smart Category Suggestions: Use AI as a tool to suggest a category for a newly entered expense. This is not required and the suggestion should be optional.
- Spending Overview: Provide a clear visual representation of spending across categories (e.g., a bar graph).
- Date Range Filtering: Allow users to filter expenses by date range (e.g., weekly, monthly, custom range).
- Data Export: Enable users to export their expense data in CSV format.

## Style Guidelines:

- Primary color: Muted olive green (#8FBC8F), inspired by financial concepts such as growth and stability.
- Background color: Very light desaturated olive (#F0FFF0) for a calm and uncluttered backdrop.
- Accent color: Soft, desaturated teal (#70A1A1), complementing the olive green for a professional and trustworthy feel.
- Font: 'PT Sans', a humanist sans-serif, should be used for both headlines and body text due to its readability and modern appeal.
- Use simple, outlined icons to represent expense categories for easy identification.
- Maintain a clean and minimalist layout to ensure a focus on financial data and ease of navigation.
- Incorporate subtle animations for data updates and transitions to enhance the user experience.
